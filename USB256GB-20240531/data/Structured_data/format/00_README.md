## アメダスおよび地上観測所について
- 気象庁では、気象データの観測をアメダスと地上観測所で行っている。
- これらの観測所のデータは、気象庁のWebページ上では「地上気象観測について」と「地域気象観測（アメダス）について」に提示されている。
- それぞれのURLは以下の通り
    - 地上気象観測について：https://www.jma.go.jp/jma/kishou/know/chijyou/surf.html
    - 地域気象観測（アメダス）について：https://www.jma.go.jp/jma/kishou/know/amedas/kaisetsu.html
- しかし、これらに掲載された情報は、断片的であり、一覧性に欠け、それらのデータがいつ掲載されたなどが明確ではない。
- 「地域気象観測（アメダス）について」内の観測所一覧では、適用日が掲載されているが、すべてではない。
- そこで、観測所のデータをとりまとめることとした。
- 以下には、その作業内容を記載する。

### 観測所のデータとりまとめにおける作業内容
- まず、「地域気象観測（アメダス）について」内の観測所一覧のから「地域気象観測所一覧 [ZIP圧縮形式]」をクリックしてZipファイルをダウンロード
- Zipファイルを解凍すると、csvファイルが入っており、そのファイルを観測所一覧の主たるファイルとする
- 主たるファイルの操作について
    - Excelで開き、csvファイルからExcel形式に変換する。シートをコピーしてシート名を「観測所一覧」とする。CSVファイルのデータは元ファイルとして、シートを残しておきシート名を「地域気象観測所一覧_20230824」とする。
    - 観測所名のカタカナ名が半角カナであったため、これを全角カナにする
    - 列幅、第一行のタイトル化、ウインドウ枠の固定は適宜行う
    - 種類の列に書かれている、観測装置の種類について、列を追加し記入
