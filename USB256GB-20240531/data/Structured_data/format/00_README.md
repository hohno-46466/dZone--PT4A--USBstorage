# 気象データに関するFormatについての説明（2024年8月3日現在）
- ここには気象庁の気象観測データ（アメダスおよび地上観測所での観測による）およびアメダスおよび地上観測所に関する情報について掲載する。

## ファイル名と内容
- 00_README.md：本ファイル
- 01-01_Observaory_station_list.csv
    - 現時点における最新版の観測地点情報
    - 種別については、以下の意味を持つ
        - 官：気象官署 → M: Manned stations and Special Automated Weather Stations
        - 四：四要素観測所 → 4: Four-Element Observatory
        - 三：三要素観測所 → 3: Three-Element Observatory
        - 雨：雨量観測所 → R: Rainfall Observatory
- 01-02_Observaory_station_list_History_amedas.csv
    - アメダス観測所の地点情報の推移のまとめ
    - 過去のデータの観測所地点番号や観測可能な項目を確認する際に使用する。
    - 元ファイルは、https://www.data.jma.go.jp/obd/stats/data/mdrr/man/kansoku_gaiyou.html
 から取得可能
- 01-03_Observaory_station_list_History_surface.csv
    - 地上観測所の地点情報の推移のまとめ
    - 過去のデータの観測所地点番号や観測可能な項目を確認する際に使用する。
    - 元ファイルは、https://www.data.jma.go.jp/obd/stats/data/mdrr/man/kansoku_gaiyou.html
 から取得可能
